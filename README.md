Generative AI Week 1 – Gemini API
📌 Project Overview
This project demonstrates how to connect a Python application to Google's Gemini AI model using the Google Gen AI SDK. It sends a text prompt to Gemini and displays the AI-generated response in the terminal.
🎯 Objectives
- Understand the basics of Generative AI.
- Connect Python to Google's Gemini API.
- Learn how to use API keys securely with environment variables.
- Send prompts to an AI model and display its response.
- Use a Python virtual environment to manage dependencies.
🛠️ Technologies Used
- Python
- Google Gemini API
- Google Gen AI SDK (google-genai)
- python-dotenv
- Visual Studio Code

⚙️ Installation and Setup
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
cd "Generative AI week -1"
Replace YOUR_GITHUB_REPOSITORY_URL with your repository URL.
2. Create a virtual environment
python -m venv .venv
Activate it on Windows PowerShell:
.\.venv\Scripts\Activate.ps1
3. Install dependencies
pip install -r requirements.txt
If you do not have a requirements.txt file, run:
pip install google-genai python-dotenv
4. Configure your API key
Create a .env file in the project root:
GEMINI_API_KEY=your_google_ai_studio_api_key
Get your API key from Google AI Studio (https://aistudio.google.com/).
Security: Never upload your actual .env file or API key to GitHub. Use .env.example with a placeholder instead.
5. Run the program
python hello_llm.py
The program sends a prompt to Gemini and prints the generated response.
